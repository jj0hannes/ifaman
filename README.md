### IFAMAN

---

An Arrival Manager (AMAN) for Infinite Flight Live Traffic.

An AMAN is an automated air traffic control decision-support tool used to sequence and meter incoming aircraft efficiently. It continuously calculates the optimal landing order and provides radar controllers with specific arrival times for defined constraint points and tactical advisories in the form of "Time to Lose" (TTL) or "Time to Gain" (TTG) instructions, allowing controllers to use speed adjustments, path stretching or holding stacks to meet target times.
